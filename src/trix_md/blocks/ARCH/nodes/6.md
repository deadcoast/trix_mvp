# ARCH-6 — Decisions

## Architecture Decision Records

### ADR-001: Four Layer Architecture
**Context:** Need clear separation of concerns.
**Decision:** 
1. Matrix UI (human)
2. Steering DB (machine)
3. Composition (operators)
4. Agent (dispatch)
**Consequences:** Clean interfaces, testable layers.

### ADR-002: File-Based Storage
**Context:** Avoid database dependencies.
**Decision:** Use markdown + YAML + JSON files.
**Consequences:** Git-friendly, portable, inspectable.

### ADR-003: Geometry Immutability
**Context:** What can operators modify?
**Decision:** Geometry (slots, coordinates) is immutable.
**Consequences:** Only bindings and content change.
