# CODE-6 — Decisions

## Code Decisions

### D001: Python 3.13+
**Decision:** Require Python 3.13 minimum.
**Rationale:** Latest features, better typing.

### D002: No Heavy Dependencies
**Decision:** Core uses only stdlib + PyYAML.
**Rationale:** Easy installation, fewer conflicts.

### D003: CLI-First
**Decision:** All features accessible via CLI.
**Rationale:** Scriptable, testable, agent-friendly.
