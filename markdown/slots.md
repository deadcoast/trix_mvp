# Default slot semantics (suggested)

These are **defaults** for the 9 node slots in a block.
You can redefine them per block if you want, but keeping a stable meaning helps agents.

```
[1] Charter / Purpose
[2] Interfaces / Inputs
[3] References / Links

[4] Backlog / Planned
[5] Now / Active
[6] Decisions / ADRs

[7] Artifacts / Outputs
[8] Validation / Checks
[9] Logs / Metrics
```
